# Admin-managed Indoor Maps

Indoor floor maps are now **admin-managed only**. The old bundled floor maps have been removed from this deployment.

1. Open Admin (gear icon) and sign in.
2. Click **Indoor Maps**.
3. Select an existing building or enter a new building name.
4. Enter the floor name.
5. Upload a JPG/PNG/WebP floor map.
6. Use Replace or Delete for existing admin-uploaded maps.

Uploaded maps are stored through Vercel Blob when `BLOB_READ_WRITE_TOKEN` is configured.
